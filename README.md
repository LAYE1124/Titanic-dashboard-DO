# Titanic-dashboard-DO
Une équipe data a réalisé une analyse exploratoire du célèbre dataset Titanic (891 passagers, 12 variables). Les résultats ont été produits dans un notebook Jupyter mais ne sont pas accessibles au reste de l'équipe. Votre mission est de transformer cette analyse en une application web Streamlit interactive, puis d'appliquer le cycle DevOps.
